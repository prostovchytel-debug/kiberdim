# КіберДім · Навігатор знань

Окрема освітня платформа: статичний клієнт на GitHub Pages, дані та API — у Supabase. Попередній сайт не замінюється.

## Можливості цієї версії

- Вхід учня без облікового запису: PIN із 6 цифр, клас, прізвище та ім’я.
- Профілі адміністратора, вчителів та учнів. Адміністратор також працює як учитель.
- Приватні тести, п’ять типів запитань, бали та час для кожного запитання, випадкова вибірка за розділами.
- Одиночний вибір, множинний вибір, відповідність, послідовність, категорії зі словами, які можна залишити у хмарі.
- Запуск для обраних класів, пауза, відновлення, завершення або скасування сеансу.
- Звіти, журнал за сеансами, CSV, рекомендації та карти досягнень за предметами.
- Зображення HTTPS / Google Drive. Ключі відповідей зберігаються лише на сервері.

## Правила оцінювання

Вартість кожного запитання задає вчитель. Одиночний і множинний вибір та послідовність оцінюються повністю за точно правильної відповіді; відповідність і категорії — пропорційно правильним елементам. Пропуск через таймер дає 0 балів.

Рівні: П — до 25% включно; С — понад 25% до 50%; Д — понад 50% до 75%; В — понад 75%. Бальна оцінка: `max(1, round(набрані / можливі × 12))`, максимум 12. Нуль балів за роботу відповідає оцінці 1.

Таймер перевіряється на сервері. При паузі зупиняється логічний час сеансу, відповіді блокуються. Повторна відправка вже прийнятої відповіді не нараховує бали вдруге. Після скасування колонка без завершених робіт зникає; завершені оцінки зберігаються, інші клітинки позначаються «С».

## Облікові записи й доступ

Паролі не зберігаються відкритим текстом. Використовується PBKDF2-SHA256; нові паролі — 600 000 ітерацій. Сесії мають випадкові токени, у базі зберігаються лише їхні SHA-256 хеші. Зміна пароля / блокування відкликає попередні сесії через версію доступу. Адміністратор може видати новий тимчасовий пароль; користувач обов’язково змінює його.

Усі таблиці мають RLS і закриті для прямого доступу браузера. Edge Function перевіряє роль і власника для кожного запиту. `verify_jwt=false` потрібне для власного входу за логіном та гостьового PIN: це не вимикає прикладну перевірку доступу. Service role ключ доступний лише у середовищі Edge Function. У клієнті міститься тільки публічний publishable key.

Гостьове ім’я вводить учень і воно не підтверджує особу. Такі результати позначені «Гість» і не прив’язуються автоматично до профілю за збігом імені. Для історії досягнень учень спочатку входить у свій профіль.

## Розробка

Потрібен Node.js 24. Залежностей npm немає.

```sh
npm test
npm run build
```

`dist/` містить лише клієнтські файли. Сервер: `supabase/functions/quiz/`. Міграція відновлена з фактично застосованої історії Supabase.

`scripts/check-integration.mjs` запускається вручну лише з тимчасовими QA-обліковими записами, описаними у `.secrets/qa.json`; цей файл ніколи не комітиться. Тест перевіряє ролі, ізоляцію власників, усі типи запитань, повторну відправку, паузу, таймер, скасування та закритий Data API. Після перевірки QA-записи потрібно видалити.

## Публікація

GitHub Actions у `.github/workflows/pages.yml` запускає тести, збирає `dist/` і публікує GitHub Pages. У налаштуваннях репозиторію **Pages → Source → GitHub Actions** має бути ввімкнено. Серверна функція розгортається окремо в Supabase.

## Межі поточного етапу

Ця версія реалізує приватні живі тести. Публічні призначення без коду, підгрупи та маршрутизація оцінок між учителями при заміні, спільний банк тестів, уроки й бібліотека HTML-симуляторів потребують окремого наступного етапу. Старі навчальні матеріали автоматично не імпортуються. Масове навантаження класів поки не випробуване; оновлення стану відбувається опитуванням кожні 4 секунди. Поточний журнал показує до 200 сеансів учителя.
